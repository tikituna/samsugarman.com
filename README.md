samsugarman.com

Plain HTML, served by GitHub Pages from the root of main. No build step.
The sound on the home page is an mp3 attached to the repository's "audio" release; the track line is in index.html. Cover thumbnails live in music/.
To look at it locally: python3 -m http.server, then open http://localhost:8000/.
The station that the home page points at, and the notes for picking all of this up, live in the sfv.fm repo: see its HANDOFF.md.
